# Penyetan 234 Bogor - Website Resmi

Website resmi untuk **Penyetan 234 Bogor**, tempat makan prasmanan pedas di Bogor Timur.

## 🌶️ Fitur Website

- ✅ Header navigasi yang sticky (tetap terlihat saat scroll)
- ✅ Animasi smooth saat scroll menggunakan AOS library
- ✅ Galeri gambar interaktif dengan lightbox
- ✅ Tampilan responsif untuk semua perangkat (mobile-friendly)
- ✅ Ikon kontak interaktif (WhatsApp, Instagram, Alamat, Customer Service)
- ✅ Desain modern dengan warna brand Penyetan 234
